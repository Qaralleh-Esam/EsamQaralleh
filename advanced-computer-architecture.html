Advanced Computer Architecture

Advanced processor architectures, parallelism, memory systems and architectural performance. Students analyze design trade-offs and evaluate modern computer systems.

Key Topics

  • Instruction-level and thread-level parallelism
  • Advanced memory systems
  • Performance and scalability
  • Architecture evaluation
