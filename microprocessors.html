Course Description

Microprocessor architecture and organization, bus architectures and assembly language fundamentals: data transfer and addressing modes, conditional and arithmetic instructions, and strings and arrays. Memory and I/O subsystems, their organization, timing and interfacing, peripheral controllers and their programming, and the practice of microprocessor system design.

The course is tightly integrated with a lab component built around an 80x86 microprocessor system. Students wire, test and troubleshoot interface hardware, run I/O interfacing experiments, and write the x86 assembly code that drives them.

Learning Outcomes

On completing the course, students will:

  1. Have a basic knowledge of microprocessor architecture.
  2. Have a working knowledge of the 80x86 instruction set.
  3. Be able to write and debug assembly programs that meet given specifications.
  4. Have a basic knowledge of memory and I/O interfaces, address decoding and bus transactions.
  5. Have a working knowledge of the interrupt-based control model, including software and hardware interrupts.
