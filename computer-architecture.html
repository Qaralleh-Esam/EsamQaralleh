Course overview

Computer Architecture and Organization

Selected teaching subject · Computer and Electrical Engineering

Course description

Processor organization, instruction sets, datapaths, memory hierarchy, pipelining, I/O and performance evaluation. Practical activities connect architectural principles with hardware implementation and verification.

Key topics

  • Instruction-set architecture and datapaths
  • Memory hierarchy and I/O
  • Pipelining and performance
  • Hardware design and verification
