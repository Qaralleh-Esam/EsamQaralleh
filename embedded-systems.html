Course Description

This course introduces the fundamental concepts of embedded systems, focusing on microcontroller architecture, hardware-software co-design, real-time operating concepts, and physical device interfacing using PIC microcontrollers.

Key Topics Covered

  • Microcontroller architectures (PIC 16F84A / 16F877A series).
  • Parallel digital I/O, switch debouncing, and display multiplexing.
  • Timers, counters, hardware interrupts, and Sleep modes.
  • Analog-to-Digital Converters (ADC) and signal conditioning.
  • Pulse-Width Modulation (PWM), H-bridge motor drivers, and sensor integration.

Project-Based Learning

Employs hands-on hardware design projects where students design, build, and test complete microcontroller-based system solutions for practical engineering applications.
