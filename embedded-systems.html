Course Description

This course introduces the fundamental concepts of embedded systems, focusing on microcontroller architecture, hardware-software co-design, real-time operating concepts, and physical device interfacing using PIC microcontrollers.

Key Topics Covered

  • Microcontroller architectures (PIC 16F84A / 16F877A series).
  • Parallel digital I/O, switch debouncing, and display multiplexing.
  • Timers, counters, hardware interrupts, and Sleep modes.
  • Analog-to-Digital Converters (ADC) and signal conditioning.
  • Pulse-Width Modulation (PWM), H-bridge motor drivers, and sensor integration.

Project-Based Learning

Employs hands-on hardware design projects where students design, build, and test complete microcontroller-based system solutions for practical engineering applications.

Document Name / Chapter Link Book & Chapter Summary
📖 Chapter 1: Microcontroller Fundamentals & PIC Architecture Introduces core embedded system principles, PIC16F microcontroller internal architecture, Harvard memory layout, CPU registers, clocking, and assembly/C program execution environment.
📖 Chapter 2: Interfacing Displays and Input Devices Details parallel I/O port programming, switch debouncing techniques, 7-segment LED multiplexing, matrix keypad decoding, and LCD display driving.
📖 Chapter 3: Pulse Width Modulation (PWM) & Applications Explores hardware PWM signal generation, frequency scaling, duty cycle mathematical modeling, and precise voltage/speed control in embedded systems.
📖 Chapter 4: DC Motors & Motor Drive Circuits Covers electromechanical principles of DC motors, H-bridge driver configurations (L298/L293D), back-EMF protection, and bidirectional motor speed/torque control.
📖 Chapter 5: Servo Motor Control Using PIC16F877 Focuses on precision position control using 50 Hz PWM control signals, SG90 and MG996R servo timing specifications, and power supply decoupling circuit design.
📖 Chapter 6: HC-SR04 Ultrasonic Sensor & Distance Measurement Analyzes acoustic time-of-flight distance calculation, trigger pulse timing, echo pulse duration measurement using timers, and real-time obstacle detection interfacing.
