Course Overview

This course introduces students to the fundamental concepts of embedded systems, focusing on the architecture, programming, and interfacing of microcontroller-based systems. Using PIC microcontrollers, students explore embedded hardware and software design, digital input/output, timers, interrupts, analog-to-digital conversion (ADC), pulse-width modulation (PWM), and serial communication. The course emphasizes practical applications through programming, simulation, and interfacing with sensors, actuators, and motors.

Course Presentation Slides & Lecture Notes

Access the presentation files for each chapter using the links in the table below:

Presentation File Chapter Summary & Topics Covered
Chapter 1.pptx Introduction to Embedded Systems: Microcontroller vs. microprocessor architecture, semiconductor memory technologies (SRAM, ROM, Flash), computer organization, and 8-bit PIC microcontroller family overview.
Chapter 2.pptx PIC Mid-Range Family & 16F84A Architecture: Program and data memory structure, status registers, Special Function Registers (SFRs), banked RAM addressing, and configuration word settings.
Chapter 3.pptx Parallel Ports, Power Supply, & Clock Oscillators: Port A/B electrical characteristics, push-pull vs. open-drain outputs, switch/LED interfacing, pull-up resistors, and RC/crystal clock oscillators.
Chapter 4.pptx Starting to Program – Introduction to Assembler: Software development cycle, PIC 16 instruction set, MPLAB IDE, MPASM assembler, software simulation with MPSIM, and downloading code to hardware.
Chapter 5.pptx Building Assembler Programs: Flowcharts/state diagrams, conditional branching, subroutines, software delay generation, bitwise logical instructions, look-up tables (retlw/addwf PCL), macros, and mikroC PRO.
Chapter 6.pptx Interrupts, Counters, & Timers: Hardware interrupt processing (INTCON, ISR, context saving, critical regions), Timer 0 (TMR0) module, prescalers, hardware delay loops, and Sleep mode.
Chapter 7.pptx Larger Systems & PIC 16F873A/16F874A/16F877A: Program memory paging (PCLATH), expanded I/O ports (Ports A–E), peripheral allocation, and system testing/diagnostic tools (emulators, debuggers).
Chapter 8.pptx Human & Physical Interfaces: Matrix keypads, 7-segment display multiplexing, switch debouncing, sensors (optical, ultrasonic, Hall effect, temperature), and motor drivers (DC, H-bridge, stepper, servo).
Chapter 9.pptx Taking Timing Further: Advanced timing features including 16-bit Timer 1, 8-bit Timer 2 (with PR2 period register and postscalers), and Capture/Compare/PWM (CCP) hardware modules.
Chapter 11.pptx Data Acquisition & Manipulation: Analog-to-Digital Converters (ADC characteristics, step size, resolution), signal conditioning, voltage scaling/translation circuits, analog multiplexing, and comparators.
