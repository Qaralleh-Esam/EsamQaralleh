Course Description

This course introduces the fundamental concepts of embedded systems, focusing on microcontroller architecture, hardware-software co-design, real-time operating concepts, and physical device interfacing using PIC microcontrollers.

Key Topics Covered

  • Microcontroller architectures (PIC 16F84A / 16F877A series).
  • Parallel digital I/O, switch debouncing, and display multiplexing.
  • Timers, counters, hardware interrupts, and Sleep modes.
  • Analog-to-Digital Converters (ADC) and signal conditioning.
  • Pulse-Width Modulation (PWM), H-bridge motor drivers, and sensor integration.

Supplementary Documents & Practical Manual

Access practical lab manuals, guides, and supplementary technical documentation for hands-on embedded systems design:

  • 📄 Interfacing Displays and Input Devices
    Comprehensive guide to 7-segment displays, matrix keypads, current-limiting, and multiplexing.
  • 📄 Pulse Width Modulation (PWM) and Its Applications
    Guide to PWM generation, duty cycle calculations, and effective voltage control using PIC microcontrollers.
  • 📄 DC Motors and Motor Drive Circuits
    Principles of DC motor operation, H-bridge drivers, torque/current specs, and microcontroller interfacing.
  • 📄 Servo Motor Control Using PIC16F877
    Guide to PWM-based servo positioning, 50 Hz control signals, SG90/MG996R specs, and power decoupling.
  • 📄 HC-SR04 Ultrasonic Sensor: Principles and Applications
    Time-of-flight distance measurement, trigger/echo timing analysis, and PIC microcontroller interfacing.
