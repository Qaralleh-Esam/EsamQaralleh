Course Description

Integrates core AI algorithms and deep learning techniques with engineering applications in smart video surveillance, medical image analysis, and edge computing deployment.

Key Topics Covered

  • Supervised and unsupervised learning algorithms.
  • Artificial Neural Networks (ANN), Convolutional Neural Networks (CNN), and RNNs.
  • Feature extraction, handwriting recognition, and license plate identification.
  • Edge AI implementation on embedded systems and IoT devices.
