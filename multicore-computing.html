Multicore & Parallel Computing

Teaches parallel architectures, thread-level parallelism, shared-memory systems, cache coherence protocols, and hardware acceleration.

Key Topics

  • Multi-core processor architectures and memory hierarchy scalability.
  • Cache coherence protocols (MESI/MOESI) and memory consistency models.
  • Parallel programming with OpenMP and multithreading.
  • FPGA hardware coprocessors and hardware-software co-design.
