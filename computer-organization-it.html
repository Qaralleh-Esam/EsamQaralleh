Computer Organization & Assembly Language

Computer instructions and assembly language, addressing modes, and instruction types: data movement, data manipulation and program control. Number representations and computer arithmetic. Computer organization: the datapath and control units, CPU operation and the instruction cycle.

Course Description

Computer instructions and assembly language, addressing modes, and instruction types: data movement, data manipulation and program control. Number representations and computer arithmetic. Computer organization: the datapath and control units, CPU operation and the instruction cycle.

The course introduces the Intel 8086/8088 processors and their internal architecture, and the x86 assembly language, so that students can carry out logical and arithmetic operations on the microprocessor. String instructions and graphical operations are also covered. The final weeks move from programming the processor to designing it: the internal architecture, the datapath and the control unit.

  • Course code22342
  • Credit hours3
  • Prerequisite22241 Digital Logic Design
  • DeliveryBlended

Learning Outcomes

On completing the course, students will be able to:

  1. Understand basic computer architecture and instruction sets.
  2. Examine how computers execute instructions and perform arithmetic operations.
  3. Examine how the datapath and control units of a CPU are designed.
  4. Understand number representation and apply computer arithmetic.
