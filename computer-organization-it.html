Course Description

Tailored specifically for Information Technology students, this course covers computer hardware architecture, memory organization, processor execution units, and assembly language programming fundamentals.

Key Topics Covered

  • Computer organization and von Neumann architecture principles.
  • Binary arithmetic, number systems, and data representation in computing.
  • Assembly language syntax, register usage, memory addressing, and control structures.
  • Basic CPU operations, bus structures, and I/O interface concepts.
  • Hands-on programming assignments and software emulator demonstrations.
